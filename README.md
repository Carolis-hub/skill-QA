# skill-QA

Skills de QA do produto Smartshare.

## Estrutura

- [`skills-qa-smartshare/`](skills-qa-smartshare) — skills atuais, organizadas por frente de trabalho (`arquitetura`, `migracao`). Cada frente contém as 9 skills modelo do processo de QA: análise de negócio, análise técnica, mapa de testes, execução de testes, análise de falha, geração de defeito, homologação de release, atualização de documentação e priorização de automação.
- [`skills-qa-smartshare/migracao/`](skills-qa-smartshare/migracao) — versão atual das skills, com ciclos executados, aprendizados e pendências (espelha o `C:\\skills-qualidade` local).
- [`legado/`](legado) — conteúdo da primeira versão (skill `smartshare-qa` com referências de processo e conhecimento do produto), mantido apenas para consulta; inclui `legado/migracao-2026-10-02/` (as 9 skills antigas da frente migração).

Mais detalhes em [`skills-qa-smartshare/README.md`](skills-qa-smartshare/README.md).
