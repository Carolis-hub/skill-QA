# Skills QA — Smartshare

Skills de QA organizadas por frente de trabalho. Cada subpasta contém as 9 skills modelo do processo:

`analise-negocio` · `analise-tecnica` · `gerar-mapa-testes-v3` · `executar-teste` · `analise-falha` · `gerar-defeito` · `homologar-release` · `atualizar-documentacao` · `priorizar-automacao`

## Frentes

- [`arquitetura/`](arquitetura) — inclui também `Analise-Negocio-Arquitetura-Share-v2.md` (análise de negócio específica da frente)
