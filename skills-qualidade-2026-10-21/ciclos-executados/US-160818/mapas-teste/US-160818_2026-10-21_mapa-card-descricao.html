Pre-requisitos gerais

Ambientes: SQL Server e Oracle, cada um com SmartShareWeb, SmartShareAgent (clássico) e o Agent/serviço net8 com a rotina da US, build com os PRs #29630 e #29631, acesso ao banco e aos logs.

  • Logs do clássico: [PASTA_AGENT_CLASSICO]\LOG\.
  • Logs do net8: [LOG_DIR_AGENT_NET8] (DEV-06).
  • Intervalo de execução: [INTERVALO_JOB]. Como forçar a execução em teste: DEV-05.
  • Chave de ativação da rotina no net8: [CHAVE_ATIVACAO_ROTINA] (DEV-01).

Massa base (cadastros pelo SmartShareWeb: Workflow > Calendário, Workflow > Data Destaque, Desenho do Processo):

MarcadorDescrição
[CAL_QA]Calendário com 1 Período: seg-sex, 08:00 às 18:00
[FERIADO_GERAL]Data Destaque marcada como feriado, cd_calendario = 0, em data dentro do intervalo de teste
[FERIADO_CAL]Data Destaque marcada como feriado, associada ao [CAL_QA]
[PROC_CALC]Processo publicado, PROCESSO.cd_calendario = [CAL_QA], 2 atividades de usuário em sequência
[PROC_PAR]Processo publicado com [CAL_QA] e um passo Paralelo com 2+ ramificações que se juntam, ainda não classificado em CONTROLE_PASSO_PARALELO
[PROC_PRAZO]Processo publicado com atividade cujo campo do formulário grava dt_prazo
[PROC_SEMCAL]Processo publicado sem calendário vinculado
[PROC_SUB]Processo publicado com passo do tipo SubProcesso (id_tipo_passo = 8)
[USR_1], [USR_2], [USR_ADMIN]Usuários executores e um com acesso à tela de configuração

Como criar a pendência de cálculo: iniciar o fluxo, avançar até concluir ao menos 1 tarefa e deixar outra em andamento. Para não esperar, ajustar datas por SQL (TAREFA, HISTORICO_TAREFA).

Procedimentos de apoio:

  • PA-CLASS: desativar a rotina no net8 ([CHAVE_ATIVACAO_ROTINA]), manter o SmartShareAgent clássico ativo, aguardar [INTERVALO_JOB].
  • PA-NOVO: parar o cálculo do clássico para o cliente, ativar a rotina no net8, forçar a execução (DEV-05).
  • PA-COMPARA: snapshot do banco, PA-CLASS e coleta, restaurar o snapshot, PA-NOVO e coleta, comparar. Diferenças aceitas: datas de execução e códigos gerados.
  • SQL-TAR-IND: SELECT * FROM TAREFA_INDICADOR WHERE cd_fluxo = [F]; (conferir nomes de colunas: vl_tempoideal, vl_tempototal, vl_tempoparcial, id_statustempo, dt_ultimaverificacao, st_somado).
  • SQL-FLX-IND: SELECT * FROM FLUXO_INDICADOR WHERE cd_fluxo = [F];
  • SQL-HIST: SELECT cd_fluxo, cd_tarefa, dt_inicio, dt_termino FROM HISTORICO_TAREFA WHERE cd_fluxo = [F];
  • SQL-CPP: SELECT * FROM CONTROLE_PASSO_PARALELO WHERE cd_processo = [P];
  • SQL-PRAZO: UPDATE TAREFA SET dt_prazo = [DATA] WHERE cd_fluxo = [F] AND cd_tarefa = [T]; (quando o campo do formulário não grava direto).
  • SQL-SEMNULO: UPDATE HISTORICO_TAREFA SET dt_termino = NULL WHERE cd_fluxo = [F] AND cd_tarefa = [T];
